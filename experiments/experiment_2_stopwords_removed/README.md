# experiment_2_stopwords_removed

Clean text with selected Somali function words removed.

Files:
- `data/train.csv`, `data/val.csv`, `data/test.csv`: splits with metadata.
- `data/clean_train.csv`, `data/clean_val.csv`, `data/clean_test.csv`: Text/Label model inputs.
- `eda/`: exploratory data analysis outputs.
- `models/traditional_ml/`: trained traditional ML model artifacts.
- `evaluation/`: metrics, classification reports, and confusion matrices.
- `xai/`: explainability outputs.
- `results/`: final comparison tables and best-model summaries.
