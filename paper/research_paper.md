# Somali AI vs Human Text Classification

## Abstract

This project studies binary Somali text classification for detecting whether a text was written by a
human or generated by AI. The supervised training labels come from `data/raw/labeled_text.xlsx`,
which contains `Text` and `Label` columns. Two controlled experiments are used: one keeps Somali
function words, while the other removes selected function words before model training.

## Dataset

The labeled dataset is stored at:

- `data/raw/labeled_text.xlsx`

The larger `data/raw/full_dataset.csv` is retained as supplemental/reference data, but it is not the
default source of supervised training labels.

After cleaning, conflict removal, and duplicate removal:

| Label | Count |
|---|---:|
| AI | 2985 |
| HUMAN | 2884 |
| Total | 5869 |

Each experiment uses a stratified 70/15/15 split:

| Split | Total |
|---|---:|
| Train | 4109 |
| Validation | 881 |
| Test | 879 |

## Experiments

| Experiment | Description |
|---|---|
| `experiment_1_stopwords_included` | Somali function words are kept. |
| `experiment_2_stopwords_removed` | Selected Somali function words are removed. |

Metrics are computed on the held-out test split. The final saved model artifacts are then refit on
the full labeled dataset (`train + validation + test`) so that deployment artifacts use all
available labeled examples.

## Traditional ML Results

Traditional ML models were trained with TF-IDF word and character features and tuned with
GridSearchCV. The full pipeline also trained Keras BiLSTM models (random embeddings, Word2Vec, and
FastText), a lightweight transformer encoder trained from scratch, and fine-tuned transformer models:
XLM-RoBERTa, mBERT, SomBERTa, AfroXLMR, and AfriBERTa.

The current results suggest that keeping Somali function words performs better for this binary
AI-vs-HUMAN classification task.

XLM-R was fine-tuned using the pretrained `xlm-roberta-base` checkpoint. Because the run was executed
on CPU, the fine-tuning setup was intentionally conservative: one epoch, `max_length=128`, with the
classifier head and final encoder block trainable. Under these constraints, XLM-R underperformed the
TF-IDF baselines and the lightweight transformer. A longer GPU run with more trainable layers would
be a reasonable future improvement.

## Explainability

XAI outputs are generated from the best LinearSVC model in each experiment:

- `experiments/experiment_1_stopwords_included/xai/outputs/`
- `experiments/experiment_2_stopwords_removed/xai/outputs/`

The outputs include package-level SHAP summaries, LIME local explanations, SHAP-like linear feature
importance, and held-out test error samples for review.

Inter-annotator agreement was not computed because `labeled_text.xlsx` contains only one `Label`
column. See `docs/inter_annotator_agreement.md`.

## Conclusion

The corrected workflow uses the labeled Excel file as the source of truth for supervised training.
The best current result is achieved by `LinearSVC_TFIDF` with Somali function words included,
reaching 0.9431 test accuracy and 0.9431 F1-score.
